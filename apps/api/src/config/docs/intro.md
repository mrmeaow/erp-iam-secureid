# ERP-IAM SecureID API Documentation

Welcome to the **SecureID** API. This service handles all authentication and authorization for the ERP-IAM ecosystem.

## Key Features

- **Fastify-powered**: High performance, low overhead.
- **RS256 JWT**: Secure token-based authentication.
- **RBAC**: Robust Role-Based Access Control.
- **Audit Logging**: All sensitive actions are logged to PostgreSQL.

## Getting Started

To use the protected endpoints, you must first register or login to receive a Bearer token. Use the `Authorize` button below to include the token in your requests.
